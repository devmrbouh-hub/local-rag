# Контрольные вопросы (для замеров качества RAG)

Ответы проверять по цитате на конкретную **статью** в файле главы.

1. Какова минимальная продолжительность ежегодного оплачиваемого отпуска в общем случае?
2. За сколько дней работник должен предупредить работодателя об увольнении по собственному желанию (общий случай)?
3. В каких случаях работодатель обязан выплатить выходное пособие при сокращении численности?
4. Что такое дистанционная работа по ТК РФ (ключевые признаки)?
5. Может ли работник отказаться от перехода на дистанционный режим, если изменены условия в одностороннем порядке?
6. Какой максимальный размер удержаний из заработной платы по исполнительным документам (общее правило)?
7. Когда допускается привлечение к сверхурочной работе без согласия работника?
8. С какого возраста допускается заключение трудового договора в общем случае?
9. Какие гарантии при направлении в служебную командировку?
10. В течение какого срока работодатель обязан ознакомить работника с приказом о дисциплинарном взыскании?
11. На какой срок по общему правилу можно установить испытание при приёме на работу?
12. Какова нормальная продолжительность рабочего времени в неделю?
13. Какое время считается ночным?
14. За сколько дней до наступления календарного года утверждается график отпусков?
15. Можно ли расторгнуть трудовой договор с беременной женщиной по инициативе работодателя?
16. Что такое неполное рабочее время?
17. В какие сроки выплачивается заработная плата?
18. По каким основаниям работодатель может расторгнуть трудовой договор по своей инициативе?
